# Reference documents

The original contribution is preserved as `UNGA81_Joyful_Responsible_Abundance_Refined.pdf`.

Add further approved public PDFs here. Use simple names such as `aukus-submission-2026.pdf`. Keep each original file unchanged; if a web-friendly copy is needed, add it as a separate file and retain the original.

Then update the matching entry in [`data/references.json`](../data/references.json), using a link such as `documents/aukus-submission-2026.pdf`. The public library will rebuild after the change reaches `main`.

The separately referenced AUKUS, Veitacini Treaty and BE LAU papers have not yet been supplied. Their existing entries 17, 18 and 19 are ready to receive files.

Only place material here that is intended for public distribution and that you have permission to share. External publications can remain external links; they do not need to be copied into this repository.
